# Crocodalias — web prototype (frozen)

The original React + Vite version of the game. It is **no longer developed**:
the product is the mobile app in [`packages/mobile`](../mobile). This version
is kept for reference only.

Game-logic fixes — turn order, score keeping, settings validation — were made
in the mobile app only, so those bugs remain here.

## Run

```bash
pnpm install
pnpm dev
```

The word decks in `public/dictionaries/ru` are a frozen copy. The maintained
word lists live in the mobile app.
